# Product photos

Save a photo here named after the product id and it replaces the generated artwork on the site automatically, with no code changes needed.

- Format: `.jpg`, roughly square, ideally 800–1200 px, product on a white or light background.
- Keep each file under ~300 KB so the site stays fast. https://squoosh.app can shrink photos for free.
- Use photos you have the right to use: your own photos of your stock, or images your supplier or the brand provides for resellers.
- To use a different filename or a full web address instead, set `image: "..."` on the product in `js/products.js`.
